# Свои спрайты мода

```
mod-sprites/
  inbox/   картинки как пришли (любые имена и форматы); в git не попадают
  raw/     исходники, разложенные по разделам и названные по схеме ниже
  game/    готовые спрайты для игры (делает конвертер, их читает игра)
  metro_convert_sprites.py   конвертер
  metro_sprites.csv          список спрайтов и их размеры (для конвертера)
```

Игра при запуске ищет папку `mod-sprites/game` (в рабочей папке, в папках поиска игры или на уровень выше папки `build`) и берёт оттуда всё, что нашла. Если файла нет — остаётся ванильный спрайт (для пешеходов — нарисованные кодом, см. ниже), так что картинки можно добавлять по одной.

## Как работать

1. Положите картинку в `inbox/` (как получилось: `photo_….jpg` и т. п.).
2. Посмотрите, что ждёт: `python mod-sprites/metro_convert_sprites.py --inbox`.
3. Назначьте каждой картинке имя — она скопируется в `raw/<раздел>/` под нужным именем:
   ```
   python mod-sprites/metro_convert_sprites.py --assign "inbox/photo_2026-11-08_11-16-58.jpg" metro/train_a_head_SE
   ```
   Можно и руками: скопировать в `raw/metro/train_a_head_SE.jpg`.
4. Запустите конвертер из корня репозитория:
   ```
   python mod-sprites/metro_convert_sprites.py
   ```
   Он для каждой картинки:
   - убирает фон: прозрачный, белый или маджента `#FF00FF` (заливкой от краёв картинки — белое внутри объекта остаётся);
   - убирает мягкие тени: серое «затемнение фона» снаружи силуэта в нижней половине объекта, у прозрачных картинок — полупрозрачные тёмные пиксели;
   - выбрасывает мелкие пятна (шум JPEG), делает прозрачность жёсткой (0 или 255), обрезает пустые поля;
   - масштабирует методом «ближайший пиксель» (nearest) под игровой размер объекта отдельно для каждого зума;
   - добавляет тёмный контур 1 px (цвет — затемнённый соседний пиксель; у грунта контура нет, грунт обрезается по ромбу тайла);
   - пишет 32-битные PNG `game/<раздел>/<имя>_1x.png`, `_2x.png`, `_4x.png`.
5. Перезапустите игру. Консольная команда `metro_sprites` показывает, какие спрайты загружены, а какие остались ванильными.

Ключи конвертера:
- `--list` — список ожидаемых файлов; `--inbox` — что лежит в `inbox/`; `--assign <картинка> <раздел/имя>` — положить картинку в `raw/`.
- `--only <часть имени>` — конвертировать только подходящие спрайты; `--clean` — сначала очистить `game/`.
- `--debug` — ещё записать очищенные картинки в полном размере в `game/_debug/` (чтобы подобрать настройки).
- Настройка очистки: `--bg-tolerance 24` (насколько пиксель может отличаться от цвета фона), `--no-shadow` (не трогать тени), `--shadow-tolerance 32` (насколько цветной может быть тень), `--shadow-min-luminance 40` (темнее — уже не тень), `--speck 0.02` (пятна меньше этой доли от самого большого куска выбрасываются).
- Вид: `--outline 1` (толщина контура в пикселях на каждом зуме, 0 — без контура), `--outline-colour 202020` (свой цвет контура вместо затемнения), `--filter box` (усреднение вместо nearest).
- `--raw <папка>` и `--out <папка>` — другие папки (для проверок).

Нужен Python 3.8+ с Pillow, numpy и scipy (`pip install pillow numpy scipy`, у вас уже стоят).

Свои спрайты из PNG работают с 32-битным блиттером (по умолчанию). При 8-битном блиттере (8bpp-optimized) остаются ванильные; пешеходы, нарисованные кодом, работают при любом.

Хорошие исходники: объект целиком, без земли и травы, на ровном белом или маджента-фоне (или прозрачном), в изометрии 2:1 как ванильные спрайты; чем крупнее, тем лучше (хотя бы размер 4x). Тень под объектом конвертер уберёт, но без тени надёжнее. Белый объект на белом фоне лучше рисовать на мадженте.

## Схема имён

`raw/<раздел>/<имя>[_<часть>].<png|jpg|jpeg|webp|bmp>` → `game/<раздел>/<имя>[_<часть>]_<1|2|4>x.png`.

- **Один спрайт:** `<имя>` — например `metro/entrance.png`.
- **Объект 2×2 (4 тайла):** `<имя>_0` … `<имя>_3`. Номер тайла — `dy * 2 + dx` от северного тайла: `0` — северный (верхний на экране), `1` — следующий по оси X (на экране вниз-влево), `2` — следующий по оси Y (вниз-вправо), `3` — южный (нижний). Каждый тайл рисуется отдельно, как у ванильных зданий.
- **Транспорт, 8 направлений:** `<имя>_N`, `_NE`, `_E`, `_SE`, `_S`, `_SW`, `_W`, `_NW` — куда едет транспорт на экране: `N` — вверх, `NE` — вверх-вправо, `E` — вправо, `SE` — вниз-вправо, `S` — вниз, `SW` — вниз-влево, `W` — влево, `NW` — вверх-влево. Хватит четырёх (`N`, `NE`, `E`, `SE`): остальные конвертер сделает зеркалом (`SW` из `SE`, `W` из `E`, `NW` из `NE`, `S` из `N`). Если нос и хвост сильно различаются, лучше нарисовать все 8.
- **Пешеход:** `pedestrian_<NE|SE|SW|NW>_<кадр 0..3>` — 4 направления × 4 кадра шага. Хватит `NE` и `SE` (спиной и лицом): `NW` и `SW` — зеркало. `NE` — идёт вверх-вправо (спиной к нам), `SE` — вниз-вправо (лицом).

## Размеры в игре

Размер — для зума 1x (обычный масштаб, тайл 64×31 пикселя), контур входит в размер; для 2x и 4x конвертер делает картинки в 2 и 4 раза больше.

- **Здания** (`building`): ширина — тайл (64 px), высота — не больше указанной; низ картинки встаёт на южный угол тайла, центр — на середину тайла.
- **Грунт** (`ground`): ровно 64×31 — ромб тайла.
- **Транспорт** (`vehicle`): вписывается в прямоугольник; центр картинки — точка транспорта, ¾ высоты над ней.
- **Пешеход** (`walker`): ноги — внизу картинки.
- **Иконки** (`icon`): 20×20, картинка вписывается по центру.

Цвет компании пока не перекрашивается (нет маски); это следующий шаг.

## Что нарисовано кодом (картинки не нужны)

- **Пешеходы** (`src/metro_walkers.cpp`): около 8 px ростом, 4 направления × 4 кадра шага, по эпохам — 1950-е (шляпа и пальто / платье), 1970-е (длинные волосы, клёш / мини), 2000-е (джинсы, кроссовки), будущее (серебристый костюм, светящийся визор); зимний (шапка с помпоном, шарф, пальто) и с зонтом. Цвет одежды — перекраска цветом компании (16 цветов), два телосложения и два оттенка кожи. Если в `game/people/` есть свой `pedestrian`, он заменяет всех.
- **Обособленный трамвайный путь** — ванильные рельсы обычной железной дороги на траве (`src/metro_trams.cpp`).

## Чего пока нет (будет, когда дойдём)

## Для разработчика

Список спрайтов хранится в двух местах, держите их одинаковыми: `mod-sprites/metro_sprites.csv` (его читает конвертер) и `src/table/metro_sprite_tables.h` (его читает игра). Загрузка — `src/metro_sprites.cpp`; места подключения вызывают `MetroSprite(id, ванильный_спрайт)`. Пешеходы кодом — `src/metro_walkers.cpp`, `src/table/metro_walker_tables.h`; консоль `metro_sprites walkers <папка>` выгружает их в PNG для просмотра.
